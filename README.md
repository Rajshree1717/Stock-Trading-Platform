TradeX is a stock trading platform that allows users to view their holdings and positions and manage stock buy orders through a simple portfolio dashboard.

Features
User-friendly trading dashboard
View stock holdings
View current positions
Place buy orders
Track trading data
Portfolio summary and management
Responsive web interface
Technologies Used
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
Other: JavaScript, HTML, CSS
